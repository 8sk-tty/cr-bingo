# パチンコ風演出ビンゴ抽選アプリ 要件定義 v0.5

## Context
- 宴会・イベントで司会者がPC1台を操作し、プロジェクタに投影して使うビンゴ抽選アプリ。
- 普通の抽選だと単調なので、パチンコ風の「保留変化 → 予告 → リーチ → 大当たり」演出で場を盛り上げる。
- 「大当たり」の意味: **一度に3個の番号を同時抽選**（ゲーム進行が一気に進む＝場が沸く）。

## 0. 体験設計（最重要）
「パチンコの見た目の抽選アプリ」ではなく、参加者が自分ごととして興奮する体験を作る。

### 0-1. 興奮の源泉とビンゴへの置き換え
| パチンコの興奮源 | ビンゴでの置き換え |
|---|---|
| 自分の損得がかかる | 参加者それぞれの「自分のリーチ番号が来るか」に演出を直結させる |
| 結果がすぐ出ない | 番号を段階的に明かす（列→十の位→一の位） |
| 惜しい外れ | 一の位がリーチ番号を通過・止まりかけて1コマ進む |
| 熱さの階層と希少性 | 色（白→青→緑→赤→金→虹）で大当たり（3個同時）期待度を示す |
| ダメそうからの逆転 | 弱い流れからの突然の確定告知（キュイン音）・復活演出 |

### 0-2. 段階的開示（コア演出）
1. 列決定: B/I/N/G/O の文字が決まる（該当列のリーチ者が前のめりになる）。文字の発光色＝大当たり期待度。
2. 十の位停止: 候補が10個前後に絞られる。1〜9 の場合は十の位が「空白」で止まり、1桁確定の瞬間として扱う。
3. 一の位減速: ゆっくり回し、候補を通過するたびに場が反応。止まりかけ→1コマ進む・再変動あり。
4. カットイン: 1〜3 の途中に割り込み、流れの熱さを煽る。
5. 確定告知: 静かな場面で突然キュイン音＋発光。鳴った時点で大当たり確定。弱い流れで鳴るのが最大の快感。
6. 大当たり: 1〜3 を3本並べて同時進行し、同時に確定。
7. 確変: 「ここで当たらないと確変終了」を残り回数で見せて煽る。

### 0-3. 品質ゲート
1. 粗い試作（段階的開示＋確定告知のみ、見た目は仮）でオーナーが「ドキッとする」か確認。通らなければ演出の型から見直す。
2. 演出・音を作り込んだ版で、オーナーが脳汁が出るか確認。
3. 最終レビュー: パチンコ愛好者の知人にレビューを依頼。

## 1. 目的・完了条件・非スコープ
- 目的: 司会者1人の操作で、公平な番号抽選とパチンコ風演出を両立させる。
- 完了条件: 1〜75の全番号を重複なく抽選しきれる／演出ランクに応じて1個 or 3個同時抽選が動く／投影画面で遠くから番号と履歴が読める。
- 非スコープ: 参加者スマホ連携、カード発行・自動判定、サーバ・アカウント・オンライン保存、実在パチンコ機のキャラ・楽曲・演出の再現（すべてオリジナル）。

## 2. 前提・制約
- 形態: 静的Webアプリ（サーバ不要）。ブラウザで開くだけ、オフラインでも動作。
- 技術: Next.js（App Router）+ TypeScript、パッケージ管理は pnpm。抽選・演出はすべてブラウザ側（Client Component）で動かし、API・DB・Server Actions は使わない。
- 演出: CSS アニメーション / Canvas を基本とし、アニメーションライブラリ（Motion、PixiJS 等）は必要になった時点で追加を確認する。
- テスト: 抽選ロジック = `bun test`、画面・操作 = Playwright。
- 配置: Vercel（Git 連携で Preview / Production デプロイ）。本番デプロイはオーナー判断。
- 画面: 16:9、1920×1080 基準。フルスクリーン対応。
- 想定ブラウザ: 最新 Chrome / Edge（司会PC）。

## 3. 用語
| 用語 | 意味 |
|---|---|
| 抽選イベント | 司会者が1回ボタンを押してから結果確定までの1サイクル |
| 保留 | 抽選前に表示されるアイコン。色が期待度（信頼度）を示す。演出専用で、溜めはしない |
| 演出ランク | その抽選イベントの熱さ。通常／青／緑／赤／金／虹 |
| 大当たり | 3個同時抽選になること |
| 信頼度 | そのランクが出たとき大当たりになる確率 |
| 確変（チャンスモード） | 大当たり後、一定回数だけ大当たり確率が上がる状態 |

## 4. 機能要件

### F1. 番号抽選（コア・公平性）
- F1-1 1〜75（設定で変更可、例: 1〜90）から重複なしで抽選。
- F1-2 番号の選択は常に一様乱数（`crypto.getRandomValues`）。演出ランクは「何個引くか」だけに影響し、どの番号が出るかには影響しない。
- F1-3 大当たり時は3個同時抽選。残り番号が3未満なら残り全部。
- F1-4 抽選順の確定はボタン押下時（演出中に結果が変わらない）。

### F2. 演出ランク抽選
- F2-1 抽選イベントごとに、①演出ランク ②大当たり可否 を確率テーブルで決定。
- F2-2 確率テーブルは設定画面で調整可能。初期値（案）:

| ランク | 出現率 | 信頼度（大当たり率） |
|---|---|---|
| 通常（白） | 60% | 0% |
| 青 | 20% | 3% |
| 緑 | 10% | 15% |
| 赤 | 7% | 50% |
| 金 | 2.5% | 90% |
| 虹 | 0.5% | 100% |

  → 1回あたり大当たり率 約8.4%（平均1.17個/回、75番号を約64回で読み切る計算）
- F2-3 「ガセ」あり: 赤・金でも外れることがある（信頼度どおり）。外れ時は1個抽選。
- F2-4 確変（ネオンラッシュ）: 大当たり後、次の5回の抽選イベントは各ランクの信頼度を +10pt（上限100%。確変中の大当たり率 約18%、5回内の連チャン率 約63%）。確変中に再度大当たりすると残り回数を5回に戻す（連チャン）。画面の色調・BGMが確変専用に切り替わる。回数・上乗せ幅は設定で変更可（初期値は仮）。
- F2-5 上限設定: 1ゲームの大当たり回数上限（初期値なし）。

### F3. 演出シーケンス
- イメージ: 劇画風カットインが割り込み、甲高い「キュイン」系SEが鳴り、番号がスロットのリールのように回って少しずつ減速し、最後にドンと確定する。
- 流れ: ボタン押下 → 保留表示（色変化あり）→ 番号変動開始（高速回転）→ 予告（カットイン等）→ 減速・リーチ（青以上）→ 確定（1個 or 大当たり3個同時）。
- F3-1 保留変化: 白で出現 → ランクまで段階的に昇格（昇格時に「キュイン」SE＋発光）。いきなり金もあり。
- F3-2 番号変動: 中央の番号が高速で切り替わり、段階的に減速。十の位→一の位の順に止まる等で焦らす。熱いランクほど減速が長く、一度止まりかけて再始動する「再変動」もあり。
- F3-3 カットイン予告: 画面を斜めに裂くようにパネルが割り込み、太字テロップ（例: 「CHANCE」「激熱」「確定!?」）＋ネオン発光。熱いランクほど出現率が高く、色（青→緑→赤→金→虹）で信頼度を示す。
- F3-4 リーチ: ノーマル／発展（背景暗転・ネオン強調）／全回転風（虹、画面全体が虹色に流れる）。ランク連動で尺と派手さが変わる。
- F3-5 確定演出: 番号が止まる瞬間に画面フラッシュ＋衝撃SE＋番号のネオン発光、軽い画面揺れ。
- F3-6 大当たり: 3個の番号を同時にドンと並べて確定。専用ファンファーレ＋全画面ネオン点滅。その後確変突入演出。
- F3-7 所要時間: 通常 約3秒、熱い演出 最大15秒。
- F3-8 スキップ: 演出中にもう一度キーを押すと結果まで早送り（結果は不変）。
- F3-9 「速抽選モード」: 演出なしで即結果（進行が押した時用）。
- F3-10 オリジナル性: 演出の「型」（カットイン、キュイン音、リール減速、確定フラッシュ）は参考にするが、キャラ・ロゴ・楽曲・セリフ・特定機種の演出構成は使わず、すべてネオンテーマのオリジナルで作る。

### F3A. ビジュアルテーマ（ネオン）
- 黒〜濃紺の背景に、蛍光ピンク・シアン・紫・黄の発光ライン。番号はネオン管風の太いフォントにグロー。
- ランク色: 白／青／緑／赤／金／虹（すべてネオン発光で表現）。
- 確変中は背景がピンク〜紫系に変わり、発光ラインが流れるアニメーション。
- キャラクターは出さない（テロップ・図形・光で演出）。

### F4. 表示（投影画面）
- F4-1 直近の抽選番号を画面中央に特大表示。大当たり時は3個同時に並べる。
- F4-2 抽選済み一覧ボード（1〜75 を B/I/N/G/O 列で表示、出た番号を点灯、直近をハイライト）。
- F4-3 抽選回数・残り番号数・確変中表示。
- F4-4 遠距離視認性: 番号は画面高さの30%以上、高コントラスト。

### F5. 司会者操作
- F5-1 キーボード操作: Space/Enter=抽選・スキップ、F=フルスクリーン、M=ミュート、Z=取り消し（直前の抽選イベントを戻す、確認あり）。
- F5-2 マウス操作でも同等の操作可能。プレゼンリモコン（PageDown等）にも割り当て。
- F5-3 リセット（新ゲーム開始、確認あり）。
- F5-4 リロードしても状態が復元される（localStorage に抽選履歴を保存）。

### F6. 音
- F6-1 BGM（通常／確変）、SE（保留出現・変化の「キュイン」系、カットイン、変動中の回転音、リーチ、確定の衝撃音、大当たりファンファーレ）。
- F6-2 音量調整・ミュート。
- F6-4 SEは自作: Web Audio API でコードから合成（例: キュイン=周波数を急上昇させる音＋うなり、確定=ノイズ＋低音の衝撃、回転音=短いパルスの連打）。音声ファイル不要で権利問題なし。
- F6-5 BGMはフリー素材 or 自作: 利用規約（商用・改変・Web公開・クレジット表記）を確認したものだけ使い、`docs/credits.md` に出典とライセンスを記録。自作する場合は BeepBox 等のツールで作曲し書き出す。
- F6-6 フォント・画像もフリー素材（Google Fonts の OFL フォント等）。ネオン表現はCSSの発光効果で作り、画像素材は極力使わない。
- F6-3 ブラウザの自動再生制限に対応（最初の操作で音を有効化）。

### F7. 設定画面
- 番号範囲、確率テーブル、確変回数、演出テンポ、音量、大当たり時の同時抽選数（初期3）。
- 設定は localStorage 保存。初期値に戻すボタン。

## 5. 非機能要件
- 公平性: 番号の偏りがないことをテストで検証（多数回シミュレーションで分布確認）。
- 性能: 1080p で 60fps 目標、司会用ノートPCで動作。
- 信頼性: 1ゲーム中にクラッシュ・状態喪失しない（リロード復元）。
- オフライン: 初回読込後はネットなしで動作（素材は同梱）。
- アクセシビリティ: 強いフラッシュは控えめにし、設定で弱められる。
- 権利: キャラ・楽曲・ロゴ・機種名など実在パチンコ機の要素は使わない。

## 6. リリース段階（案）
1. 手触り試作: F1 抽選コア + 段階的開示（0-2 の 1〜3, 5）+ 仮の音と見た目 → 品質ゲート1
2. MVP: F4 表示 + F5 操作 + 演出ランク・保留変化・大当たり3個同時（F2, F3 の骨格）
3. 演出・音の作り込み: カットイン、リーチ、確変、ネオン、SE/BGM（F3, F3A, F6）→ 品質ゲート2
4. 設定画面・調整（F7）→ 品質ゲート3（知人レビュー）

## 7. 決定事項・未決事項
### 決定済み（2026-11-12）
- 大当たり3個は同時にドンと確定。
- 確変あり（初期値: 5回・信頼度+10pt・連チャンで回数リセット、要調整）。
- テーマはネオン、キャラクターなし。
- 演出の型: カットイン＋キュイン音＋番号が少しずつ変わる減速＋確定フラッシュ。
- 素材: SEは Web Audio で自作、BGM・フォントはフリー素材（規約確認・クレジット記録）または自作。

### 未決
- 確変の初期値（5回・+10pt）はプレイテストで調整。
